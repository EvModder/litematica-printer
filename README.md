# Litematica Printer

A fork of [IceTank/litematica-printer](https://github.com/IceTank/litematica-printer), the 2b2t-optimized printer fork.

## Changes from upstream

- Builds every pushed commit as a 90-day GitHub Actions artifact, and retains the [latest successful build](https://github.com/EvModder/litematica-printer/releases/download/latest-build/litematica-printer-latest-mc1.21.4.jar).

Usage, 2b2t setup guides (grim bypass configs), and limitations are documented in the [upstream README](https://github.com/IceTank/litematica-printer#readme).

Build with `./gradlew build` (Java 21).
